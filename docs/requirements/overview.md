# Salesfolia 要求仕様・要件定義

## 1. プロジェクト概要とコンセプト
- **システム概要**: レガシーな専用業務機からの完全移行をターゲットとした、統合型業務システム（ERP）。
- **テナントモデル**: マルチテナント型B2B SaaS。企業（テナント）ごとにデータを論理分離し、複数企業へサービスとして提供する。
- **コアUX（ユーザー体験）**: 
  - **「キーボード操作で完結」**を徹底。マウスを一切使わずとも、もたつきのない高速なデータ・伝票入力が可能であること。
  - Enterキーでのフォーカス移動、ショートカットキーによる操作、即座のマスター検索などを必須とする。

## 2. 開発・リリースロードマップ（アジャイル形式）
アジャイル開発の手法を取り入れ、短いサイクルで機能ごとにリリースと改善を繰り返す。

0. **フェーズ0：開発環境構築**
   - Devbox, Mise等を用いたモダンなローカル開発環境のセットアップ
1. **フェーズ1：システム基盤構築**
   - マルチテナント環境のベース構築
   - 認証機能・権限管理（テナント > グループ > ユーザー）の基盤作成
2. **フェーズ2：顧客管理機能**
3. **フェーズ3：商品管理機能**（倉庫管理を含む）
4. **フェーズ4：売上請求管理**
5. **フェーズ5：仕入買掛管理**
6. **フェーズ6：受注管理**
7. **フェーズ7：発注管理**
8. **フェーズ8：見積管理**
9. **フェーズ9：生産管理**

> 技術スタック・アーキテクチャの詳細は [docs/requirements/00_environment.md](./00_environment.md) を参照。
